# HarmonyOS Sans

Menus and editor tools use the unmodified HarmonyOS Sans fonts supplied by Huawei.
Copyright 2021 Huawei Device Co., Ltd.

The complete HarmonyOS Sans Fonts License Agreement is bundled at
`Assets/Resources/Fonts/HarmonyOS/LICENSE.txt` and imported as a runtime TextAsset.
The font files may be embedded and distributed with this application under that
agreement; they must not be modified or distributed as standalone font software.

Included faces: SC Regular, SC Medium, SC Bold, Regular, Medium, Bold, and
Condensed Medium. Japanese menus retain the existing Rodin fonts. Noto Sans CJK
remains the missing-character fallback (see ArtTools.md for its existing notice).

All runtime resources are resolved from the repository. The original external
font installation directory is not required for a build or for running a player.
